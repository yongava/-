🙏 ฉากสักการะพระพิฆเนศ หน้าควบคุม

กำลังเชื่อมต่อโปรแกรม…

1. เชื่อมต่อไลฟ์ TikTok

ยังไม่ได้เชื่อมต่อไลฟ์

กดเชื่อมต่อก่อนเริ่มไลฟ์ได้เลย ถ้ายังไม่ได้ไลฟ์ โปรแกรมจะรอและเชื่อมต่อให้เองเมื่อไลฟ์เริ่ม

2. ใส่ฉากใน TikTok LIVE Studio

  1. เปิด TikTok LIVE Studio แล้วกด เพิ่มแหล่งที่มา (Add Source) เลือก ลิงก์ (Link)
  2. วางลิงก์ด้านล่าง ตั้งขนาด กว้าง 1080 สูง 1920
  3. ลากให้เต็มจอแนวตั้ง แล้วเริ่มไลฟ์

ถ้าอยากให้เห็นกล้องด้านหลัง ใช้ลิงก์แบบพื้นหลังโปร่งใส:

3. ทดสอบฉาก (ไม่ต้องไลฟ์จริง)

อย่าลืมปิดการจำลองก่อนเริ่มไลฟ์จริง

4. ผู้ดำเนินไลฟ์

พิมพ์ข้อความให้เสียงพูดอ่านในไลฟ์ หรือกดประโยคสำเร็จรูป

5. เสียงพูดและดนตรี

ให้พูดเมื่อ

ตั้งค่าในกล่องนี้บันทึกทันทีที่เปลี่ยน · ถ้าในไลฟ์ไม่มีเสียง ให้เปิดเสียงของแหล่งที่มาแบบลิงก์ใน LIVE Studio หรือเลือกเล่นเสียงที่หน้าควบคุมนี้แทน

6. ตั้งค่าฉาก

การคิดแต้มพลังศรัทธา

รูปองค์พระพิฆเนศ

ฉากมีองค์พระพิฆเนศทองคำที่วาดไว้แล้ว ถ้าอยากใช้รูปองค์พระของคุณเอง (รูปที่ถ่ายเองหรือมีสิทธิ์ใช้ PNG พื้นหลังโปร่งใสสวยที่สุด) เลือกรูปที่นี่ · เอฟเฟกต์คล้องพวงมาลัยและถวายขนมจะย้ายไปลงที่แท่นบูชาแทน
