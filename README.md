# Honeycomb Pickleball Paddle

ไม้พิกเกิลบอลแบบชิ้นเดียว ไม่มีแผ่นผิวหน้า หน้าไม้เป็นรังผึ้งหกเหลี่ยมที่ทะลุตลอดความหนา
ยึดด้วยขอบตันรอบหน้าไม้ และต่อเป็นชิ้นเดียวกับด้ามจับทรงแปดเหลี่ยม

<img src="preview.png" width="260" alt="Paddle preview">

## ไฟล์

| ไฟล์ | รายละเอียด |
| --- | --- |
| `pickleball_paddle.stl` | ด้านล่างด้ามเรียบเสมอกับหน้าไม้ วางนอนพิมพ์ได้โดยไม่ต้องใช้ซัพพอร์ต |
| `pickleball_paddle_symmetric.stl` | ด้ามอยู่กึ่งกลางความหนาของหน้าไม้ จับได้สมดุลกว่า แต่ต้องใช้ซัพพอร์ตตอนพิมพ์ |
| `generate_paddle.py` | สคริปต์สร้างโมเดล ปรับค่าได้จากค่าคงที่ที่ส่วนบนของไฟล์ |

## ขนาด

| | |
| --- | --- |
| ความยาวรวม × ความกว้าง | 400 × 197 mm (15.75 × 7.75 in, รวม 23.5 in ซึ่งกติกากำหนดไม่เกิน 24 in) |
| ความหนาหน้าไม้ | 13 mm |
| ความยาวด้าม | 133 mm (5.25 in) |
| ด้ามแปดเหลี่ยม | 36 × 24 mm, เส้นรอบวง 108 mm (4.25 in) |
| รังผึ้ง | ระยะห่างช่อง 15 mm, ผนังหนา 1.0 mm, 272 ช่อง |
| ขอบตันรอบหน้าไม้ | 4.5 mm |
| น้ำหนักโดยประมาณ | 230 g (8.1 oz) เมื่อใช้ PETG/PLA และด้ามเติมเนื้อประมาณ 35% |

## การพิมพ์

- ฐานพิมพ์ต้องยาวอย่างน้อย 400 mm (ฐาน 350×350 ต่อให้วางทแยงก็ยังไม่พอ)
- วางนอนให้หน้าไม้แนบฐาน
- แนะนำ PETG เพราะทนแรงกระแทกดีกว่า PLA
- ตั้งเส้นผนัง 2 เส้น กว้างประมาณ 0.5 mm, เลเยอร์ 0.2 mm, ด้ามใช้ infill แบบ gyroid ประมาณ 15–20%

## สร้างใหม่

```sh
pip install manifold3d numpy
python3 generate_paddle.py                    # pickleball_paddle.stl
python3 generate_paddle.py --grip symmetric   # pickleball_paddle_symmetric.stl
```

## ข้อควรรู้

กติกา USA Pickleball ไม่อนุญาตให้หน้าไม้มีรู ไม้นี้จึงใช้แข่งในรายการที่รับรองไม่ได้ เหมาะกับการเล่นสนุกหรือซ้อม
